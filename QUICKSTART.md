# 🚀 DÉMARRAGE RAPIDE - APPLICATION ÉTIQUETTES v1.0.0

## Installation en 3 minutes ⏱️

### 1️⃣ Extraire l'archive
```
Décompresser etiquette-app-v1.0.0.zip dans :
📁 C:\xampp\htdocs\              (Windows)
📁 /Applications/MAMP/htdocs/    (Mac)
📁 /var/www/html/                (Linux)
```

### 2️⃣ Démarrer les services
```
✅ Ouvrir XAMPP Control Panel
✅ Démarrer Apache
✅ Démarrer MySQL
```

### 3️⃣ Installer
```
🌐 Ouvrir navigateur : http://localhost/etiquette-app/install.php
✨ Suivre l'assistant (tout est automatique)
🗑️ Supprimer install.php après
```

### 4️⃣ Utiliser !
```
🏠 Accéder : http://localhost/etiquette-app/
🎯 Choisir : Sartorius ou Latitude
🏷️ Créer vos premières étiquettes !
```

---

## ✨ Première utilisation

### Sartorius
1. Cliquer "Étiquettes Sartorius"
2. Cliquer "Référence" → Ajouter "REF-TEST" + "Produit Test"
3. Cliquer "Nouveau" → Sélectionner référence, remplir formulaire
4. PDF généré automatiquement ! 🎉

### Latitude
1. Cliquer "Étiquettes Latitude"
2. Cliquer "Article" → Ajouter "Carte postale"
3. Cliquer "Nouveau" → Remplir formulaire
4. PDF généré automatiquement ! 🎉

---

## 🆘 Problèmes courants

### ❌ Erreur "Connection failed"
**Solution** : Vérifier que MySQL est démarré dans XAMPP

### ❌ Page blanche
**Solution** : Vérifier que Apache est démarré

### ❌ PDF non créés
**Solution** :
```bash
chmod 777 pdfs/
chmod 777 pdfs_latitude/
```
